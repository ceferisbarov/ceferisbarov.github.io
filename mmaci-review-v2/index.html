How to Review MMACI Families

What you are reviewing: Each family tests an AI assistant on a realistic workplace, academic, clinical, or personal task where sharing too much—or acting before resolving an ambiguity—causes an inappropriate disclosure.

How a family is structured:

  • Base / Real variants (World A vs. World B): The initial prompt or workspace leaves a material fact unresolved. Depending on the hidden world, asking the user (or checking workspace records) leads to different ground truth and a different right action.
  • Control variants: The missing fact is provided up front (or the attachment is pre-cropped), testing whether the assistant can complete the task directly when no ambiguity exists.

Visual overlays: On images and audio/video, green regions (Share) show information required to complete the task, and red dashed regions (Withhold) show bundled information that should not be disclosed to the task recipient. Click any row in the Variant Comparison Matrix to switch the active variant overlay.

Saving & Sharing: Answers autosave in this browser (`localStorage`). Click Export JSON when you finish a sitting and send the downloaded `.json` file to the organizer.
